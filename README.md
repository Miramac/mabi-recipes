# Mabi Recipes

A clean, mobile-first recipe app built with React and Tailwind CSS.

## Features

- Browse and search recipes
- Filter by category (Breakfast, Lunch, Dinner, Dessert, Snack)
- View full recipe detail with ingredients and step-by-step instructions
- Add and edit your own recipes
- All data stored locally in your browser (no account needed)

## Tech Stack

- [Vite](https://vitejs.dev/) + [React 19](https://react.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [React Router v7](https://reactrouter.com/)
- localStorage for persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
